# Right to Reply Test

Test source configuration for **Right to Reply**, an independent, politically neutral right-of-reply project for officially registered UK political parties.

This repository publishes one fictional example response for testing the browser extension. It does not represent a participating political party. The extension reads `party.json`, `identifiers.json` and the Markdown files listed in `party.json` from `main`. Proposed party contributions must be made through a public pull request and reviewed under exactly the same rules for every party.

- [Editorial and participation rules](CONTENT_POLICY.md)
- [How to contribute and supply public evidence](CONTRIBUTING.md)

Published responses are plain text only: a one-line response and an extended description of up to 255 characters, with no links. Source links and discussion belong in the public PR, not the extension.
